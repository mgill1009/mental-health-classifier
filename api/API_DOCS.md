# API — Local Setup & Testing

## Requirements

- Python 3.11+
- scikit-learn **1.8.0** (must match the version used to save `pipeline.pkl` in notebook 02 — any other version will throw an `InconsistentVersionWarning` or an `AttributeError` on load)
- Both model artefacts saved to the correct paths:
  - `models/baseline/pipeline.pkl` — generated by notebook 02
  - `models/distilbert/distilbert-mental-health/` — generated by notebook 03

---

## Starting the API

```bash
cd api
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

On startup you should see both models load:

```
INFO  main  TF-IDF model ready.
INFO  model_loader  [distilbert] Loaded in Xms — device=cpu
INFO  main  DistilBERT model ready.
INFO  Application startup complete.
```

If either model fails to load, check that the paths above exist relative to the project root.

---

## Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Minimal health check |
| GET | `/health` | Shows which models are loaded + uptime |
| GET | `/labels` | Returns the label mapping (0/1/2 → risk tier) |
| POST | `/predict?model=tfidf` | Inference using TF-IDF + Logistic Regression |
| POST | `/predict?model=distilbert` | Inference using fine-tuned DistilBERT |

Interactive docs (auto-generated by FastAPI) available at:
**http://localhost:8080/docs**

### DistilBERT — same text, higher confidence

```bash
curl -X POST "http://localhost:8080/predict?model=distilbert" \
  -H "Content-Type: application/json" \
  -d '{"text": "I have not been able to get out of bed for weeks"}'
```

```json
{
  "risk_tier": 2,
  "risk_label": "High Risk",
  "confidence": 0.9353,
  "probabilities": {
    "Low Risk": 0.0629,
    "Moderate Risk": 0.0018,
    "High Risk": 0.9353
  },
  "model": "distilbert",
  "latency_ms": 392.545
}
```

Both models agree on **High Risk**. DistilBERT is significantly more confident (93.5% vs 62.6%) because it understands the sentence contextually — TF-IDF is less certain because the text lacks explicit keywords like "depression" or "suicidal".

> **Note on latency:** DistilBERT is running on CPU locally. First call is ~390ms; subsequent calls drop to ~70ms once the CPU kernel is warm. On a GPU (as used during training on Colab), p99 was 15ms.

### TF-IDF vs DistilBERT — indirect distress (anhedonia)

This is one of the documented false negative cases from the evaluation. Both models miss it because the text contains no distress keywords and is grammatically positive. Resolving this class of error would require conversational context beyond a single post.

```bash
curl -X POST "http://localhost:8080/predict?model=tfidf" \
  -H "Content-Type: application/json" \
  -d '{"text": "my dog is the only thing that gives me genuine joy lately"}'
```

```json
{
  "risk_tier": 0,
  "risk_label": "Low Risk",
  "confidence": 0.6985,
  "probabilities": {
    "Low Risk": 0.6985,
    "Moderate Risk": 0.0861,
    "High Risk": 0.2155
  },
  "model": "tfidf",
  "latency_ms": 4.322
}
```

```bash
curl -X POST "http://localhost:8080/predict?model=distilbert" \
  -H "Content-Type: application/json" \
  -d '{"text": "my dog is the only thing that gives me genuine joy lately"}'
```

```json
{
  "risk_tier": 0,
  "risk_label": "Low Risk",
  "confidence": 0.9547,
  "probabilities": {
    "Low Risk": 0.9547,
    "Moderate Risk": 0.001,
    "High Risk": 0.0443
  },
  "model": "distilbert",
  "latency_ms": 67.969
}
```

Both predict **Low Risk** (incorrect — this expresses anhedonia). Notably DistilBERT is *more* confident in the wrong answer (95.5% vs 69.9%), which illustrates the model's limitation on implicit, positively-framed distress. This is part of the 14 remaining High Risk → Low Risk false negatives documented in notebook 03.

## Known Issues & Fixes

### `InconsistentVersionWarning` on pipeline load
The `pipeline.pkl` was saved with scikit-learn 1.8.0 (Colab). Loading it with any other version will throw warnings and may throw errors. Fix:
```bash
pip install scikit-learn==1.8.0
```
